# Assessment records

The dated files in this directory are immutable evidence from completed Baron
release and phase checks. They describe the source revision and contract that
was tested at the time; they are not a second current command reference.

For the current public model, use the repository [README](../../README.md),
[architecture](../architecture/ARCHITECTURE.md), and the
[status dashboard](../BARON_STATUS.md). Assessment reports remain useful for
auditing proof, release, migration, memory, and cross-platform behavior.
