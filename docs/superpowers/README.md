# Superpowers plans and specifications

The dated plans and specifications here are engineering records. They preserve
the decisions, tests, and evidence for each completed phase and are retained
for review. They do not override the current source or the maintained product
documentation.

The active plan is linked from [`docs/superpowers/plans/CURRENT.md`](plans/CURRENT.md)
and the durable phase dashboard at [`docs/BARON_STATUS.md`](../BARON_STATUS.md).
Current user and integration behavior is described by the repository
[README](../../README.md) and the architecture pages. When an older plan uses a
previous adapter layout or command flow, treat it as historical context and
follow the current Core ownership contract.
